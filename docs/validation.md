## 发布版核心测试

```powershell
npm test
npm run check
```

默认不访问豆包，不调用专用表格运行库；临时文件只在测试临时目录。包含发送/恢复、已发送保护、命名、观察状态、归档、问题匹配、双份复制和人工结果等逻辑。

核心测试使用合成短表预览夹具；它只验证执行器如何消费结构化计划，不冒充实际Excel解析。需要专用表格库或可选模板的8个集成用例默认跳过，测试输出会明确列出。原版在完整本机依赖和模板下有173项通过记录；不把那一数字冒充本发布版默认全部通过。

2026-11-03发布整理验证：默认核心测试165项通过、8项跳过、0失败；冻结旧B流程校验通过，54条自动发送原文与原开发版一致。发布版窗口源码编译通过，100%/125%/150%缩放的离屏布局检查通过，未Show窗口或连接真实豆包。本轮未执行专用Excel后端集成测试。

## 可选Excel集成测试

```powershell
npm run test:xlsx
```

仅在具备兼容且获授权的表格后端时运行；本仓库不附该库。样例短表可测试真实导入及回填。完整复现旧B和66行验证还需要未随仓库提供的兼容本地模板：

- examples/legacy/旧豆包B测评集_全过程与独立问题表.xlsx
- examples/optional/long-flow.xlsx（原66行、60自动＋6人工结构）

可选模板不存在时仍会报告跳过。默认测试和XLSX集成测试都不发送真实产品消息；实机行为需另行在专用评测账号验收。Windows窗口的布局辅助检查位于tests/ProgressBarCheck.cs。
