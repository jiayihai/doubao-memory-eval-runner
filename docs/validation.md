# V1.8.0 验收与维护说明（2026-11-04）

本版仅修复初始状态勾选区遮挡，并将 Excel 预览、通用回填、旧 B 回填和辅助工具迁移至公开 ExcelJS 4.4.0 / JSZip 3.10.1。发送、等待、命名、断点与原回复归档逻辑未改变。

- 开发主线保留 1.7.0 修改前 63 个文件基线及 SHA-256 清单；原 451 个运行文件哈希保持一致。公开安装快照不包含历史基线或真实运行记录。
- 196 项离线回归通过、0 跳过，覆盖真实 xlsx 导入/导出、6 条和 66 条流程模拟、旧 B 54 条回填、公式实际引用核验、共享公式缓存、字面等号回复、错误公式拒绝和原表不变。
- 原生窗口 100%/125%/150%/175%/200% 缩放及 930/980/1360 三种宽度离屏检查通过；勾选区按内容自适应，不再依赖固定 32 像素高度。
- 已在全新公开目录通过安装依赖.ps1 完成 npm ci、Excel 写入重读和窗口构建，无专用库或目录连接。所有公开依赖按 package-lock.json 锁定。
- 原输入模板不改；结果仍保存在本轮及原 Excel 同目录。新后端保留关联公式，核对实际计算值后刷新回答/状态缓存，保存后重新读取核对内容和格式。其他评分公式由表格软件重算。
- ExcelJS 不是通用公式计算器，支持范围及已知 npm 间接依赖告警见 docs/dependencies.md。图表、图片、宏、透视表、外部链接和无法核验的回答公式会明确拒绝。
- 本次没有连接真实豆包、发送测评消息、改变当前暂停任务或更新线上 GitHub；真实页面与结果显示仍需用户验收。

建议验收：关闭旧窗口，打开 1.8.0。先观察勾选区，再校验 examples/short-flow.xlsx；运行 5 自动＋1 人工短流程，核对两张表共 6 行处理、3 问题回答、结果双份保存及问题表公式显示。通过后换长表。不要把离线模拟和旧版实测算作本版真实豆包通过。
