# 依赖与复现边界

| 部分 | 条件 | 本仓库包含什么 |
| --- | --- | --- |
| 核心离线测试 | Node.js 22.15以上 | 模拟适配器、合成夹具及测试；不需要第三方包 |
| Windows窗口 | Windows、.NET Framework 4.8编译器、Node | C#源码和构建脚本；不附exe |
| 实际豆包操作 | 桌面端、登录的专用评测账号、可用CDP调试连接 | CDP协议与豆包页面适配源码；不含登录信息 |
| Excel预览/回填 | 原型专用的兼容表格后端 | 适配代码；不含运行库或公开安装方案 |

## Excel后端

三个工作进程使用`@oai/artifact-tool`的导入、单元格读取/写入、公式重算和导出接口。原型曾在具备该库的本机环境下验证；它没有作为可公开安装依赖写入package.json，仓库也不复制该库、缓存、二进制或目录连接。

因此：普通克隆环境可以运行核心测试、阅读和构建源码，但不能直接复现Excel导入/回填；`npm install`不能补齐这部分。只有另行具备合法可用环境，或后续自行实现兼容后端后，才能运行完整链路。缺库时工作进程会明确报错，不把失败说成处理成功。

后端边界集中在tools/spreadsheets/preview-worker.mjs、backfill-worker.mjs和excel-results-worker.mjs。未来替换为公开实现，需要重新验证公式保留、非目标区域不变、完整正文及原模板不改等要求；本次发布整理未做此功能替换。

## 本机配置

- Node：先找程序目录的node.exe，再找NODE_EXECUTABLE环境变量及PATH。
- 豆包：在窗口选择实际exe，或设置DOUBAO_EXECUTABLE；首次没有作者机器的默认路径。
- 调试端口：默认9223，可在窗口修改。
- 运行后产生的账号、路径、断点和正文存于运行数据/或对话导出/，均被.gitignore排除。

构建脚本为兼容Windows PowerShell 5.1保留UTF-8 BOM。请保留仓库结构；旧B兼容模板若另行准备，默认放examples/legacy/旧豆包B测评集_全过程与独立问题表.xlsx，当前未提供。
