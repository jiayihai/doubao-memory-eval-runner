# 双工作表输入规范

第1行从A列开始为表头，按字段名识别列；步骤ID采用S加正整数，按数字部分升序执行。一行代表一条用户消息。

## 全过程执行表

| 字段 | 含义 |
| --- | --- |
| 步骤ID | 唯一执行节点，不另设顺序ID |
| 身份ID | 逻辑身份；本版仅一个AUTO身份 |
| 会话ID | 首次出现创建并命名，再出现返回本轮原会话 |
| 消息类型 | HISTORY或QUESTION，均从用户侧发送 |
| 问题ID | QUESTION必填，与独立问题表唯一对应；HISTORY留空 |
| 发送内容 | 实际完整原文，不改写 |
| 回复后等待秒数 | 完整回复保存后等待，0—604800整数秒 |
| 执行方式 | AUTO或MANUAL |
| 实际回答 | 结果副本中回填，空模板保持空白 |
| 执行状态 | 模板为未执行，结果记录完成或跳过 |
| 异常说明 | 模板空白，结果记录时间不确定、跳过原因等 |

可增加执行约束；人工时间锚点字段为“计时锚点问题ID”“距锚点最早秒数”“距锚点最晚秒数”，须引用更早的问题并完整填写。自动节点时间锚点未接入。含人工追加且消息编号未经核验的同一会话，暂不能自动续写。

## 独立问题表

必需列：问题ID、用例ID、测评能力、测试问题、预期回答要点、评分标准、实际回答、执行状态。

问题原文须与全过程对应QUESTION完全一致。若附步骤ID、身份ID、会话ID或前置问题ID，也校验对应关系。问题ID唯一，用例ID可包含多个问题。评分标准由后续评分者使用，脚本不自动评分。

## 结果约定

所有回复回填全过程；QUESTION按问题ID同步问题表。不直接修改输入模板，而是另存结果Excel。保留关联公式及评分字段，已完成只表示执行和取回成功。人工粘贴明确标注来源，缺少平台ID和精确回复时间时不伪造；前提不满足可说明原因并跳过，不填写成0分。

随机间隔未实现；输入/问题/预期/评分不支持动态公式。回答/状态可保留兼容的已有公式。长回答保存全文，但Excel单元格上限仍为32767字符；更多实现细节以core/dataset-preview.mjs为准。
