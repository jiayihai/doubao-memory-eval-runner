# 6条合成短流程

- [short-flow.xlsx](short-flow.xlsx)：用于已配置Excel后端的技术验收；不含真实个人信息或真实产品回答。
- [short-flow.preview.json](short-flow.preview.json)：与样例输入相对应的结构化预览夹具，仅供不依赖Excel库的核心测试；不是运行结果或Excel解析的替代证明。

流程：M0连续两条→新建T01→返回M0→人工H01→返回M0。总计5条AUTO＋1条MANUAL、3个问题。等待为短秒数，便于观察。

第5步需要在同一测试账号手动新开独立H01会话，发送该行原文，保存首次完整回复；返回执行器人工窗口粘贴并确认，再回主窗口继续。不要把该行追加到自动M0或T01，以免产生未核验的额外消息。

仅用于验收发送、归属、保存和恢复，不据此评分产品记忆能力。大规模与旧B回填模板未包含；可选集成测试的本地模板位置见[测试说明](../docs/validation.md)。
