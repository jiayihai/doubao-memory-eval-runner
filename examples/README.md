# 测试文件怎么选

首次运行选 **[入门测试_6条.xlsx](入门测试_6条.xlsx)**。它与 short-flow.xlsx 是同一份已用于离线回归的样例，中文文件名便于找到。原文件输出列留空，每次结果另存。

| 文件 | 用途 |
| --- | --- |
| 入门测试_6条.xlsx | 首次完整流程验收：5 自动＋1 人工、3 问题、3 会话。 |
| short-flow.xlsx | 与入门表字节一致，保留此名供既有测试及开发工具使用。 |
| long-flow.xlsx | 后续较长流程：66 行，60 自动＋6 人工。先读执行约束再运行。 |
| legacy/旧豆包B测评集_全过程与独立问题表.xlsx | 旧 B 合成健康档案表，用于兼容核对；不是首次使用的短流程。 |

## 入门表逐步预期

| 步骤 | 会话 | 执行 | 预期操作 | 回复标记 |
| --- | --- | --- | --- | --- |
| S0001 | M0 | 自动 | 新建并命名，发送第 1 条 | OK1 |
| S0002 | M0 | 自动 | 在同一会话发送 | OK2 |
| S0003 | T01 | 自动 | 新建并命名，发送测试问题 | OK3 |
| S0004 | M0 | 自动 | 返回原会话发送 | OK4 |
| S0005 | H01 | 人工 | 在同一测试账号手动新建独立会话，按窗口原文发送、录入首次完整回复 | MANUAL_OK |
| S0006 | M0 | 自动 | 人工保存后点击“继续本轮”，返回 M0 发送 | OK6 |

按表内短间隔等待，等待从完整回复确认后起算。标记是供人工核对的约定，实际回复会原样保存；执行器不会替使用者评分。入门消息是技术测试文字，不用于测量记忆能力。

第 5 步显示“处理人工步骤”属于正常流程。完整操作见 [README 的首次使用步骤](../README.md#4-第-5-条人工停点怎么处理)。全部完成且未跳过时，应有 6 行处理结果、3 个问题回答和对应会话备份；原表保持空白，结果双份另存。

使用已有表格软件可先查看内容；执行器读取和写回不要求安装 Excel。文件可以复制到其他可写目录再选择，不需要修改脚本中的路径。
